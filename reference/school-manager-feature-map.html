01

School Admin Panel

SCHOOL_ADMIN

Poora system yahin se control hota hai — school ka setup, staff, fees, exams, sab kuch. Har doosra role isi ka ek chhota hissa dekhta hai.

Academic setup

  • Academic years, classes, sections banana
  • Subjects list, har section ko subjects assign karna
  • Elective subjects — subject ko "elective" mark karke sirf kuch students ka roster banana (O/A-Level combinations)
  • Weekly timetable builder, per-section

Students (SIS)

  • Admission entry, guardian linking, bulk CSV import
  • Profile edit, section transfer, class promotion (year-end)
  • Transfer certificate issue (PDF)
  • Parent/Student portal login provisioning
  • Photo upload

Custom fields

  • School-specific extra fields define karna (text/number/date/yes-no/dropdown)
  • Har student ke against value save karna
  • Field disable/retire (data safe rehta hai)

Attendance

  • Daily section-wise marking
  • Attendance summary/history per student

Exams & results

  • Exam banana, subject-wise max/passing marks set karna
  • Marks entry roster (per exam-subject)
  • Grading bands configure karna (A/B/C wagera ke cutoffs)
  • Report card generate — single ya bulk/ZIP (poori class ke liye ek saath)

Fees

  • Fee categories aur class-wise fee structure
  • Bulk invoice generation (poore section ke liye)
  • Payment record karna (cash/cheque/bank — manual)
  • Defaulter list, challan PDF, late-fee policy

Staff

  • Staff records, roles assign karna
  • Payroll generate karna, cancel/approve
  • Leave request approve/reject

Discipline

  • Incident log (category + severity + action liya gaya)
  • Guardian ko turant SMS/WhatsApp notify karna

Learning support

  • Support plan log karna (learning/attention/speech wagera)
  • Periodic review add karna, status update

Health records

  • Har student ka health profile (blood group, allergies, emergency contact)
  • Clinic-visit / first-aid log

Analytics

  • Live dashboard — enrollment, attendance rate, fee collection, exam performance
  • 6-month trend charts

Communication

  • Notices (school-wide announcements)
  • Notification log — SMS/WhatsApp/Email dispatch status

Settings

  • School colour theme (branding)
  • Weekly off days configure karna
  • Apni profile aur password
02

Teacher Panel

TEACHER

Sirf apne assigned sections/subjects tak scoped — kisi doosre class ka data nahi dekh sakta.

My classes

  • Apna weekly timetable, day-wise
  • Apne sections ki list

Attendance & marks

  • Apne section ki attendance mark karna
  • Apne subject ki marks entry (roster auto-filtered — elective ho to sirf enrolled students)

Homework

  • Apne section/subject ko homework assign karna

Discipline & support

  • Apne section ke student ka incident log karna
  • Learning support plan log karna (read + log, review nahi)

Health

  • Clinic-visit log karna (profile edit nahi kar sakta, sirf padh sakta hai)

Own account

  • Leave request bhejna
  • Notices/notifications dekhna
03

Front Desk Panel

FRONT_DESK

Roz-marra ka office/reception kaam — admission entry se le kar guardian aur health-desk tak.

Students & guardians

  • Naya admission entry karna, CSV import
  • Guardian add/link karna
  • Section transfer, TC issue

Attendance & health

  • Attendance marking
  • Health profile edit + clinic-visit log (first-aid desk)

Fees (read + collect)

  • Invoice dekhna, payment record karna
  • Challan print karna

Custom fields

  • Student ke extra field values bharna (jo admin ne define kiye)
04

Accountant Panel

ACCOUNTANT

Poora finance module — is role ke ilawa sirf School Admin ko itni fee-visibility milti hai.

Fees — full control

  • Fee categories, structure, bulk invoice generation
  • Payment recording, defaulter list
  • Late-fee policy, challan PDF

Payroll

  • Staff payroll generate karna

Read-only

  • Students, staff list (billing context ke liye)
  • Exam results (fee-linked reporting)
05

Platform Admin Panel

SUPER_ADMIN

Ye humara (SaaS operator) apna internal panel hai — kisi school ke andar ka data nahi, balke sab schools (tenants) ko upar se manage karne ke liye.

Tenant management

  • Har school (tenant) ki list, status (active/suspended)
  • Plan change karna (Trial/Basic/Standard/Premium)

Overview stats

  • Total schools, active count
  • New signups — last 7 din, last 30 din
Ye panel har school ke data se alag/isolated hai — Row-Level Security ke zariye guarantee hai ke ek tenant ka data doosre ko kabhi nahi milta.
06

Parent / Student Portal

PARENT · STUDENT

Ek hi portal, do roles serve karta hai — PARENT apne sab bachon ka data dekh sakta hai, STUDENT sirf apna. Sab kuch read-only hai (sirf leave request bhej sakte hain).

Student profile

  • Basic profile, section, guardian info

Academic

  • Attendance history
  • Exam results, report card

Fees

  • Invoice aur payment history dekhna
  • (online payment abhi nahi — manual/cash entry hi visible hoti hai)

Wellbeing

  • Discipline records dekhna
  • Learning support plan dekhna
  • Health profile + clinic-visit log dekhna

Requests & notices

  • Student leave request bhejna, cancel karna
  • School notices dekhna
  • Apna profile/password
